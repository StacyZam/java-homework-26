## Предметная область: Книжный магазин

Класс `Book` моделирует учёт книжных изданий в магазине и содержит 4 обязательных атрибута:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `title` | `String` | Название книги |
| `author` | `String` | Автор (имя и фамилия / инициалы и фамилия) |
| `year` | `int` | Год выпуска конкретного тиража/издания |
| `price` | `double` | Стоимость в рублях |
